# Specifications (`docs/specs/`)

Tempat dokumen spesifikasi fitur baru Pipstride.

Alur:
1. Fitur non-trivial dirancang terlebih dahulu dengan `/spec <nama-fitur>`.
2. Spek mendefinisikan problem, constraints, perancangan interface/API/skema data, dan kriteria sukses.
3. Setelah disetujui, spek dipecah menjadi tiket eksekusi mandiri di folder `tickets/`.
